# ORBIT Starfield Planner v1.1 (fixed)

This fixes Learn buttons appearing unclickable because challenges were hidden in the Skill Library.

## Update GitHub Pages
Replace your existing `index.html` with this version at the same website URL. Your local browser save is retained because the site and storage key are unchanged. Make a JSON backup first.

## Switch to a downloaded HTML file
Open the original app and select **Export** first. Open the updated HTML, choose **Character > Import save**, and select that JSON file. Do not reset your original app. Local saves might not follow you between different files or URLs.

## Updates
- Roadmap and overview show skill challenges with inline checkboxes.
- Blocked Learn buttons can be tapped and always explain what is needed.
- The Skill Library also shows lock reasons.
- Buying from the wrong future roadmap row cannot silently purchase another rank.
- Existing v1 JSON saves import into v1.1.
